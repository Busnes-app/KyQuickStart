# Everyday tasks

## Installation workflow

Keep the saved state directory for resume. Review product selections, dependencies, placement and edge configuration before applying. Skipping an installed product does not authorize deleting it. Preserve manually owned networks, credentials and persistent storage.

## Existing products

The `integrate-identity`, `integrate-product` and `integrate-stack` commands connect supported running products to KyIdentity. Verify provisioning, explicit administrator grants and everyday access separately; a successful OIDC login proves only sign-in.

## Public routing and handover

Use `verify-edge` to check routing and forwarded headers. Review actual observed results and unresolved gates before treating the installation as complete. Keep the handover record securely; administrator and everyday identities have separate duties.

## Rehearsals

Use isolated targets and the documented demo mode. Disable production push relays on throwaway instances. Do not point a rehearsal at production data or assume a successful demo establishes product readiness.
